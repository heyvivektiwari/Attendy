# Database Cabinet

This folder is the designated storage area for local database files (such as SQLite `.db`, `.db-shm`, `.db-wal` files).

> [!NOTE]
> **PostgreSQL Production Connection**:
> The Attendy production application uses a cloud PostgreSQL database (Supabase / Neon) via the `DATABASE_URL` connection string specified in `.env.local` or Vercel environment variables.
